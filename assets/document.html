The HTML view

This page is an HTML file from the program's asset bundle, laid out and drawn by Adi.Widget.Html_View. It is a reader for documentation-style markup, not a browser: no scripts, no network, and every image and stylesheet comes through a callback the program supplies.

Inline text

Text runs can be bold, italic, underlined, struck through, marked, small or code. Keys read Ctrl+T. Lines wrap at whitespace and never inside a word.

Lists

  • Unordered items take a marker from list-style-type.
  • Nested lists indent:
    • a second level
    • with its own marker
  1. Ordered lists count.
  2. Each item is a block.
